# AutobaseApp

Небольшой чат для двух человек. В проекте есть две версии:

- веб-версия в браузере (`web_chat.py`);
- консольная TCP-версия (`chat_server.py` + `chat_client.py`).

Обе версии работают на стандартной библиотеке Python и не требуют внешних зависимостей.

## Требования

- Python 3.10 или новее.

## Веб-версия

### Запуск на одном компьютере

1. Запустите веб-сервер:

   ```bash
   python3 web_chat.py
   ```

2. Откройте в браузере:

   ```text
   http://127.0.0.1:8000
   ```

3. Откройте тот же адрес во втором браузере, во второй вкладке или в режиме инкогнито.
4. Введите имена участников и начните переписку.

Веб-чат принимает максимум двух участников. Если третий человек попробует подключиться, он увидит сообщение, что чат занят.

### Запуск по локальной сети

На компьютере-сервере запустите приложение так, чтобы оно слушало все сетевые интерфейсы:

```bash
python3 web_chat.py --host 0.0.0.0 --port 8000
```

На устройствах участников откройте в браузере IP-адрес сервера:

```text
http://192.168.1.10:8000
```

Замените `192.168.1.10` на реальный IP-адрес компьютера, где запущен сервер.

## Консольная TCP-версия

### Запуск на одном компьютере

1. Запустите сервер:

   ```bash
   python3 chat_server.py
   ```

2. В новом терминале подключите первого участника:

   ```bash
   python3 chat_client.py
   ```

3. В третьем терминале подключите второго участника:

   ```bash
   python3 chat_client.py
   ```

4. Введите имя участника, затем пишите сообщения. Для выхода отправьте:

   ```text
   /quit
   ```

### Запуск по локальной сети

На компьютере-сервере укажите адрес, доступный другим устройствам:

```bash
python3 chat_server.py --host 0.0.0.0 --port 5000
```

На компьютерах участников подключитесь к IP-адресу сервера:

```bash
python3 chat_client.py --host 192.168.1.10 --port 5000
```

Замените `192.168.1.10` на реальный IP-адрес сервера.

## Структура проекта

- `web_chat.py` — веб-приложение: отдаёт страницу чата, принимает сообщения по HTTP и отправляет новые сообщения через Server-Sent Events.
- `chat_server.py` — консольный TCP-сервер, который принимает два подключения и пересылает сообщения.
- `chat_client.py` — консольный TCP-клиент, который подключается к серверу, отправляет и получает сообщения.
