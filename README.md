# AutobaseApp

Небольшой чат для двух человек. В проекте есть три версии:

- статическая веб-версия без Python (`index.html`);
- серверная веб-версия в браузере (`web_chat.py`);
- консольная TCP-версия (`chat_server.py` + `chat_client.py`).

Статическая версия работает без Python. Серверная веб-версия и консольная версия работают на стандартной библиотеке Python и не требуют внешних зависимостей.

## Требования

- Для статической версии: любой современный браузер.
- Для серверной веб-версии и консольной версии: Python 3.10 или новее.

## Статическая версия без Python

Самый простой вариант — открыть готовый сайт напрямую в браузере:

1. Найдите файл `index.html` в папке проекта.
2. Откройте его двойным кликом или перетащите файл в браузер.
3. Введите имя, выберите участника и отправляйте сообщения.
4. Для второго участника откройте этот же файл во второй вкладке и выберите «Участник 2».

Эта версия сделана только на HTML, CSS и JavaScript. Она не требует Python, установки пакетов или запуска сервера. Сообщения синхронизируются между вкладками одного браузера через `BroadcastChannel` и сохраняются локально в `localStorage`.

Важно: полностью статический сайт без сервера не может сам по себе пересылать сообщения между разными компьютерами через интернет или локальную сеть. Для такого сценария нужна серверная версия ниже или внешний сервис синхронизации.

## Веб-версия

### Запуск на одном компьютере

1. Запустите веб-сервер:

   ```bash
   python3 web_chat.py
   ```

2. Откройте в браузере:

   ```text
   http://127.0.0.1:8000
   ```

3. Откройте тот же адрес во втором браузере, во второй вкладке или в режиме инкогнито.
4. Введите имена участников и начните переписку.

Веб-чат принимает максимум двух участников. Если третий человек попробует подключиться, он увидит сообщение, что чат занят.

### Запуск по локальной сети

На компьютере-сервере запустите приложение так, чтобы оно слушало все сетевые интерфейсы:

```bash
python3 web_chat.py --host 0.0.0.0 --port 8000
```

На устройствах участников откройте в браузере IP-адрес сервера:

```text
http://192.168.1.10:8000
```

Замените `192.168.1.10` на реальный IP-адрес компьютера, где запущен сервер.

## Консольная TCP-версия

### Запуск на одном компьютере

1. Запустите сервер:

   ```bash
   python3 chat_server.py
   ```

2. В новом терминале подключите первого участника:

   ```bash
   python3 chat_client.py
   ```

3. В третьем терминале подключите второго участника:

   ```bash
   python3 chat_client.py
   ```

4. Введите имя участника, затем пишите сообщения. Для выхода отправьте:

   ```text
   /quit
   ```

### Запуск по локальной сети

На компьютере-сервере укажите адрес, доступный другим устройствам:

```bash
python3 chat_server.py --host 0.0.0.0 --port 5000
```

На компьютерах участников подключитесь к IP-адресу сервера:

```bash
python3 chat_client.py --host 192.168.1.10 --port 5000
```

Замените `192.168.1.10` на реальный IP-адрес сервера.

## Структура проекта

- `index.html` — статический сайт чата без Python и без сервера.
- `web_chat.py` — серверное веб-приложение: отдаёт страницу чата, принимает сообщения по HTTP и отправляет новые сообщения через Server-Sent Events.
- `chat_server.py` — консольный TCP-сервер, который принимает два подключения и пересылает сообщения.
- `chat_client.py` — консольный TCP-клиент, который подключается к серверу, отправляет и получает сообщения.
