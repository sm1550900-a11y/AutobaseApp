Чат для двоих

Обычный сайт на HTML, CSS и JavaScript. Его можно открыть двойным кликом — Python, сервер и установка пакетов не нужны.

● Без Python

Пока сообщений нет. Напишите первое сообщение снизу. Для второго участника можно открыть этот файл во второй вкладке и выбрать другую сторону.

Как пользоваться

  1. Откройте файл index.html в браузере.
  2. Введите имя первого участника и отправьте сообщение.
  3. Для второго участника откройте этот же файл во второй вкладке и выберите «Участник 2».
  4. Если нужна отдельная переписка, поменяйте название комнаты.
Это полностью статический сайт. Он хорошо подходит для демонстрации и общения между вкладками одного браузера. Для настоящего чата между разными компьютерами нужен сервер или внешний сервис синхронизации.
